# excel/

Exploratory and validation layer. Excel is used here to interrogate the data quickly and to recalculate the published totals independently of SQL and Power BI, not as the final reporting surface.

**Workbook:** `saas_revenue_churn_analysis.xlsx`

| Analysis | Purpose |
|---|---|
| Overall churn | Establish the headline retention position |
| Monthly churn trend | Check whether churn is improving, stable or worsening |
| Churn by plan | Locate the tier carrying the retention problem |
| Churn by billing cycle | Compare monthly against annual commitment |
| Churn by company size | Test whether churn concentrates by customer size |
| Churn by acquisition channel | Connect retention quality to go-to-market source |
| Churn reasons | Summarize self-reported cancellation drivers |
| Customer behavior comparison | Compare adoption, NPS and support activity for churned against retained customers |
| Revenue trend | Review the 48-month MRR trajectory |
| CLV and CAC view | Provide directional unit-economics context |
| Risk indicators | Size the low-adoption, low-NPS active population |

Every total in this workbook is reconciled against the SQL output and the Power BI measures before publication. Control totals are listed in [../docs/methodology.md](../docs/methodology.md).
